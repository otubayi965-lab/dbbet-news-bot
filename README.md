# ربات پست خودکار اخبار فوتبال - DBbet World

این ربات به صورت خودکار:
1. جدیدترین خبر فوتبال رو از منابع RSS رایگان می‌گیره
2. متن رو با سبک اختصاصی بازنویسی می‌کنه (اگه کلید Claude بدی، وگرنه با یک قالب ساده)
3. روی عکس خبر، نوار مشکی + متن هدلاین + نام کانال رو اضافه می‌کنه
4. عکس + کپشن رو در کانال تلگرام پست می‌کنه
5. یادش می‌مونه چه خبرهایی رو قبلاً پست کرده تا تکراری نشه

## مرحله ۱: ساخت ربات تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده
2. دستور `/newbot` رو بزن و اسم/یوزرنیم انتخاب کن
3. توکنی که می‌ده رو نگه دار (چیزی شبیه `123456:ABC-DEF...`)
4. ربات رو به عنوان **ادمین** کانال DBbet World اضافه کن (با دسترسی ارسال پیام)

## مرحله ۲: پیدا کردن آیدی کانال
اگه کانال یوزرنیم عمومی داره (مثل `t.me/DBbetWorld`)، آیدی همون `@DBbetWorld` است.
اگه خصوصیه، باید عددی شبیه `-1001234567890` رو با یک ربات کمکی مثل @userinfobot پیدا کنی.

## مرحله ۳: آپلود در گیت‌هاب
1. یک ریپازیتوری جدید بساز (public کافیه و رایگانه)
2. تمام فایل‌های این پوشه رو در ریپازیتوری آپلود کن (همون ساختار پوشه‌ها رو حفظ کن)

## مرحله ۴: تنظیم Secrets
در ریپازیتوری برو به:
`Settings > Secrets and variables > Actions > New repository secret`

سه مقدار زیر رو اضافه کن:
- `TELEGRAM_BOT_TOKEN` → توکن ربات از BotFather
- `TELEGRAM_CHANNEL_ID` → آیدی کانال (مثل `@DBbetWorld`)
- `ANTHROPIC_API_KEY` → (اختیاری) کلید API کلود، اگه می‌خوای متن با هوش مصنوعی بازنویسی بشه. اگه نذاری، از قالب ساده استفاده می‌کنه.

## مرحله ۵: تست دستی
برو به تب **Actions** در ریپازیتوری، روی workflow با اسم
"Post football news to Telegram" کلیک کن و دکمه **Run workflow** رو بزن.
اگه همه‌چیز درست باشه، یک پست جدید در کانال ظاهر می‌شه.

بعد از این، ربات خودش هر ۳۰ دقیقه یک‌بار به‌طور خودکار اجرا می‌شه.

## نکات مهم
- فایل `state/posted.json` رو دستکاری نکن؛ خود ربات این فایل رو به‌روزرسانی و کامیت می‌کنه.
- برای فونت فارسی/انگلیسی بهتر، یک فایل `.ttf` (مثل Vazir یا IRANSans) رو در `assets/font.ttf` قرار بده؛ در غیر این صورت از یک فونت ساده پیش‌فرض استفاده می‌شه.
- می‌تونی فهرست `RSS_FEEDS` داخل `bot.py` رو با هر منبع خبری فوتبالی دیگه‌ای که دوست داری جایگزین یا تکمیل کنی.
- زمان‌بندی (`cron: "*/30 * * * *"`) رو در `.github/workflows/post.yml` می‌تونی به هر بازه‌ای که خواستی تغییر بدی.
